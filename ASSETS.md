# Asset licences

Every asset in this project is either generated at runtime by the game's own
code, or is the single third-party model listed below. **No asset from any
commercial game is used, referenced, or reproduced.**

## Generated at runtime — no licence required

Everything below is produced by this project's own source at load time. None of
it is a file, and none of it derives from third-party artwork.

| Category | Produced by | What is generated |
|---|---|---|
| **Surface textures** | `src/world/textures.js` | Asphalt, concrete, plaster, dirt, corrugated metal, wood plank, roof tile, painted container steel and woven hessian. Each is a value-noise/fBm albedo baked to a canvas, with a roughness map and a normal map derived from the same height field by a Sobel filter; the container panel also bakes a metalness map so rust stops answering light like bare steel. Fuel drums reuse the container bake rotated a quarter turn. |
| **Surfaces for the new maps** | `src/world/biomes.js` | Forest floor (soil, leaf litter, moss), granite with lichen and cracks, wind-packed snow, bark, broadleaf foliage, pine needles, log-cabin walls with chinking, heavily rusted plate, catwalk grating, factory brick. Same pipeline as above - one height field per surface, albedo and roughness shaded from it, normals by Sobel - built only when a map that needs them is loaded. The furnace glow is a plain emissive material. |
| **Instanced props** | `src/world/props.js` | Pines (green and snow-covered), broadleaf trees, boulders (bare and snow-covered, also scaled up as the distant mountains), felled logs, stumps, bushes, storage tanks (painted and rusted), the radar dome, pipes, a smokestack and lamp posts. Every shape is built from primitives displaced by a smooth field so it reads as organic, and drawn with InstancedMesh. |
| **Sky** | `src/world/textures.js` | Equirectangular gradient with an fBm cloud layer, used as both background and environment map. Each map passes its own zenith, horizon, ground and cloud colours and cloud cover: Dustline's desert dusk, Timberline's green-grey overcast, Whiteout's bright white overcast, Foundry's orange smog. |
| **Sprites and decals** | `src/world/textures.js` | Muzzle-flash star, soft radial blob (contact shadows, smoke), bullet-hole decal with rim and radial cracks. |
| **All weapon models** | `src/weapons/models.js` | Ten weapons plus three lethals, built from chamfered extrusions, tubes and boxes: receivers, barrels, handguards, rails, optics (iron / red dot / holographic / ACOG / 8× scope), magazines, stocks, muzzle devices, moving bolts and slides. |
| **Camouflage** | `src/game/camo.js` | The patterns behind all 337 skins: sixteen tileable patterns from value noise and jittered cells (blotch, digital, tiger stripes, rosette spots, hexagon plates, woven fibre, veined marble, scales, circuit traces, damascus layers, crystal shards, nebula with stars, aurora curtains, volcanic cracks, a neon grid, brushed metal), projected three ways onto guns and fatigues, some animated in the shader (drift, glow pulse, hue rotation); plus a painted studio gradient for the metal skins to reflect. |
| **First-person arm and legs** | `src/game/skins.js`, `src/chars/characters.js` | No separate model: the operator mesh is cut by skin weight into a body twin (stomach down) and a left-arm twin that share its vertices; the arm is posed by IK for the punch and the ledge grab, with the fingers closed by axes the game finds from the rig itself. |
| **Blood pool field** | `src/world/textures.js` | `makePoolTexture`: when a spreading pool's front reaches each texel (angular harmonics for the lobes, fbm for the ragged edge), read by the pool shader in `src/game/effects.js`. |
| **Character gear** | `src/chars/characters.js` | Helmet (shell, brim, NVG mount, side rails, faction band, chin strap, optional goggles), plate carrier (front/back plates, shoulder pads, magazine pouches, radio, antenna, faction placard and shoulder tapes), thigh holster rig. |
| **Aircraft** | `src/game/killstreaks.js` | Attack helicopter (fuselage, tail boom, stabilisers, skids, stub wings, rocket pods, chin turret, articulated main and tail rotors, nav lights) and two jets (conventional and flying-wing stealth). |
| **The maps** | `src/world/map.js`, `src/world/maps/` | All four - MP_DUSTLINE, MP_TIMBERLINE, MP_WHITEOUT and MP_FOUNDRY - in their entirety: every wall, floor, staircase, catwalk, container, tree trunk, boulder, tank and wreck, from one list of axis-aligned boxes per map mirrored through a 180-degree rotation, with the instanced props placed over their collision boxes. |
| **All audio** | `src/core/audio.js` | Every sound in the game, synthesised with hand-written DSP: layered gunshots (transient crack, low-end body, mechanical action, outdoor tail with early reflections) in five rotated variants per weapon plus distant-report variants, footsteps per surface, bullet impacts per surface, explosions, mechanical clicks, supersonic whizz-by, rotor and jet loops, wind ambience, UI blips, and the convolution reverb impulse response. |
| **All interface art** | `src/ui/style.css`, `src/game/hud.js`, `src/game/menu.js` | Reticles, scope reticle and lens vignette, minimap, compass ribbon, killstreak icons, killfeed weapon glyphs, tactical map. All inline SVG or 2D canvas. |

## Fonts

No font files are shipped. The interface uses a system font stack
(`Bahnschrift`, `DIN Alternate`, `Roboto Condensed`, `Segoe UI`, `system-ui`)
with a monospace stack for numerals, falling back to whatever the platform has.

## Naming

Weapon, operator and map names are original to this project. Any resemblance to
real firearms is at the level of a general class of weapon (assault rifle, bolt
gun, machine pistol), which is not protectable, and no trademarked designation
is used.
