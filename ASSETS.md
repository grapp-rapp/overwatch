# Asset licences

Every asset in this project is either generated at runtime by the game's own
code, or is the single third-party model listed below. **No asset from any
commercial game is used, referenced, or reproduced.**

## Generated at runtime — no licence required

Everything below is produced by this project's own source at load time. None of
it is a file, and none of it derives from third-party artwork.

| Category | Produced by | What is generated |
|---|---|---|
| **Surface textures** | `src/world/textures.js` | Asphalt, concrete, plaster, dirt, corrugated metal, wood plank, roof tile, painted container steel and woven hessian. Each is a value-noise/fBm albedo baked to a canvas, with a roughness map and a normal map derived from the same height field by a Sobel filter; the container panel also bakes a metalness map so rust stops answering light like bare steel. Fuel drums reuse the container bake rotated a quarter turn. |
| **Sky** | `src/world/textures.js` | Equirectangular dusk gradient with fBm cloud layer, used as both background and environment map. |
| **Sprites and decals** | `src/world/textures.js` | Muzzle-flash star, soft radial blob (contact shadows, smoke), bullet-hole decal with rim and radial cracks. |
| **All weapon models** | `src/weapons/models.js` | Ten weapons plus three lethals, built from chamfered extrusions, tubes and boxes: receivers, barrels, handguards, rails, optics (iron / red dot / holographic / ACOG / 8× scope), magazines, stocks, muzzle devices, moving bolts and slides. |
| **Character gear** | `src/chars/characters.js` | Helmet (shell, brim, NVG mount, side rails, faction band, chin strap, optional goggles), plate carrier (front/back plates, shoulder pads, magazine pouches, radio, antenna, faction placard and shoulder tapes), thigh holster rig. |
| **Aircraft** | `src/game/killstreaks.js` | Attack helicopter (fuselage, tail boom, stabilisers, skids, stub wings, rocket pods, chin turret, articulated main and tail rotors, nav lights) and two jets (conventional and flying-wing stealth). |
| **The map** | `src/world/map.js` | MP_DUSTLINE in its entirety — every wall, floor, staircase, container, barrier, sandbag emplacement and wreck — from one list of axis-aligned boxes, mirrored through a 180° rotation. |
| **All audio** | `src/core/audio.js` | Every sound in the game, synthesised with hand-written DSP: layered gunshots (transient crack, low-end body, mechanical action, outdoor tail with early reflections) in five rotated variants per weapon plus distant-report variants, footsteps per surface, bullet impacts per surface, explosions, mechanical clicks, supersonic whizz-by, rotor and jet loops, wind ambience, UI blips, and the convolution reverb impulse response. |
| **All interface art** | `src/ui/style.css`, `src/game/hud.js`, `src/game/menu.js` | Reticles, scope reticle and lens vignette, thermal gunner overlay, minimap, compass ribbon, killstreak icons, killfeed weapon glyphs, tactical map. All inline SVG or 2D canvas. |

## Fonts

No font files are shipped. The interface uses a system font stack
(`Bahnschrift`, `DIN Alternate`, `Roboto Condensed`, `Segoe UI`, `system-ui`)
with a monospace stack for numerals, falling back to whatever the platform has.

## Naming

Weapon, operator and map names are original to this project. Any resemblance to
real firearms is at the level of a general class of weapon (assault rifle, bolt
gun, machine pistol), which is not protectable, and no trademarked designation
is used.
