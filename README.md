# OVERWATCH: BLACKOUT

A browser tactical FPS. Rigged soldiers driven by real mocap, learnable recoil
patterns, bone-accurate hit registration, killstreaks, killcams, and a small
symmetric map you can learn in three matches.

```bash
npm start        # → http://localhost:8099
```

No build step. Static files only.

---

## What's in it

**Every operator is a rigged, skinned, textured humanoid** driven by real
animation clips through a `THREE.AnimationMixer` — not a shape assembled from
primitives. Locomotion crossfades idle → walk → run with the clip's playback rate
locked to actual ground speed, so strides match travel and nobody skates. The
hips turn toward the velocity vector while an additive twist runs up the spine to
the aim direction, which is what makes strafing read correctly from a single
forward walk cycle. Two-bone IK puts the right hand on the grip and the left on
the foregrip; the weapon is parented to the hand *bone*, so it inherits every bit
of skeletal motion. On death the mixer stops and the body falls under a short
rigid-body solve while the skeleton relaxes to a limp pose.

**Hitboxes are capsules between bone pairs**, so hit registration follows the
animation exactly — head, neck, chest, gut, four arm segments, four leg segments.
A leaning, sprinting target really is a harder shot.

**Ten weapons that feel different**, measured: eight distinct time-to-kill values
at 10 m. Assault rifles, an SMG, a semi-auto shotgun, an LMG, a marksman rifle, a
bolt-action .408 under a true 8× magnifying scope, and three sidearms. Each has
its own recoil pattern — a deterministic, learnable sequence with a little
gaussian jitter on top — its own spread bloom, ADS time, movement penalty and
reload behaviour (the shotgun reloads shell by shell and you can cancel it to
fire).

**Recoil is an aim offset, not a camera shake.** Firing moves where the barrel
points; you pull down to stay on target and the view recovers toward where it
was when you stop. The round leaves the barrel before the gun moves, so the first
shot of a magazine goes exactly where the sights are pointed.

**The AI is honest.** A bot knows where you are only if it has line of sight
through the same geometry your bullets travel through, inside its view cone, for
longer than its reaction time. Gunfire gives it a *guess*, not a position, and it
will walk to that guess and be wrong. It paths the map — including up both
staircases and onto the catwalks — takes cover, flanks, leads its shots, reloads
behind cover, and can be beaten.

**Everything you hear is synthesised at boot.** A gunshot is four layers: the
transient crack, a pitch-swept low-end body, mechanical action a few tens of
milliseconds behind, and an outdoor tail with discrete early reflections whose
length and colour are per-weapon. Five full variants per weapon play in a shuffled
rotation, plus duller long-tailed versions for distant fights. Footsteps and
impacts vary by surface.

**Everything you see except the character model is generated by code** — the
textures (albedo, roughness and Sobel-derived normals from the same height
field), the sky, every weapon, all the gear, the aircraft, and the entire map.

## Controls

| | |
|---|---|
| **W A S D** | Move |
| **Shift** | Sprint |
| **Ctrl / C** | Crouch |
| **Space** | Jump / vault a window sill |
| **LMB / RMB** | Fire / aim down sight |
| **R** | Reload |
| **1 / 2 / Q** | Primary / secondary / quick swap |
| **G** | Lethal (hold to cook a frag) |
| **V** | Melee |
| **B** | Cycle fire mode |
| **H** | Hold breath (scoped) |
| **5 / 6 / 7** | Call in an earned killstreak |
| **Tab** | Scoreboard |
| **Esc** | Pause |

Mouse and trackpad have separate pointer profiles — the trackpad gets an
acceleration curve and a smoothing window because a short swipe has to cover 180
degrees.

## The map

MP_DUSTLINE, 62 × 46 m, three lanes, 180° rotationally symmetric so neither team
has an advantage. Two two-storey compounds with staircases and upper-floor
firing positions overlooking the centre, two open warehouses with catwalks, a
raised centre pad with ramps and sandbag emplacements, shipping containers,
jersey barriers and a wrecked truck. Spawns are scored at selection time against
every live enemy and never place you where one can already see you.

## Project layout

```
index.html            import map + all UI structure
src/
  main.js             boot, render loop, lighting, LOD and culling
  core/               input, synthesised audio, shared maths
  world/              procedural textures, the map, collision, navmesh, cover
  chars/              rigged character, animation stack, IK, hit capsules
  weapons/            weapon table, procedural models, shot resolution, viewmodel
  ai/                 perception, states, pathing, cover selection, aiming
  game/               match flow, HUD, menu, effects, killcam, killstreaks
  ui/style.css        interface
tools/
  serve.mjs           static dev server
  check.mjs           parses every module with the real JS parser
  inspect.mjs         dumps a .glb's node, bone and animation tables
  qa-browser.js       the test harness (see BUILD_NOTES)
  qa-capture.js       screenshot pipeline (WebGL + composited HUD)
dev/chartest.html     character rig / animation / IK inspector
qa/                   captured screenshots
```
